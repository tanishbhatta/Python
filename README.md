# Python

This repository contains my Python learning journey, from basic exercises and practice programs to larger projects and capstone work.

I’m using it to keep track of what I learn, experiment with different ideas, and build things as I get more comfortable with Python.

## What's inside

The repository is organized into different stages of my learning:

- `Practice` contains smaller exercises and experiments.
- `Phase4_Functions` focuses on functions and related concepts.
- `Phase5_DataCollection` contains work related to collecting and handling data.
- `Miscellaneous-Projects` contains smaller projects and ideas that don't fit into a specific phase.
- `CapstoneA` through `CapstoneE` contain larger projects built as part of my learning process.

## What I'm learning

Some of the main areas covered in this repository include:

- Python fundamentals
- Functions
- Data handling
- Problem solving
- Working with projects
- Writing and organizing Python code

This repository is still a work in progress. As I learn more, I'll keep adding new experiments, projects, and larger programs.

## Why this exists

I'm keeping this repository public so I can see how my code changes over time instead of letting everything disappear into random folders on my computer.

The goal is simple: learn by building, make mistakes, figure them out, and gradually write better code.
